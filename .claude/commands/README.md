# Slash Commands

| Command | When to use |
|---------|-------------|
| `/plan` | Before coding — design the approach in conversation |
| `/autopilot` | Build a scoped task start to finish: branch → commits → PR → review → merge |
| `/review` | Check the current branch for bugs, determinism breaks, spec drift, DRY |
| `/debug` | Something is broken — reproduce, root-cause, propose a fix |
| `/balance` | Run the headless bot sim and judge the numbers against the pass bars |
| `/explain-simple` | Explain what just happened in plain English |

**Per-feature loop:** `/plan` → `/autopilot` → `/review` → `/balance` (if gameplay changed) → `/explain-simple`.
